# Diagnóstico Inicial · Focux Labs

Cuestionario del Diagnóstico Inicial de Focux Labs (español e inglés).
Se rellena en el navegador; las respuestas se guardan solo en el navegador de quien
lo contesta hasta que las descarga o las envía.

Este repositorio solo contiene el cuestionario vacío. Se actualiza desde el proyecto
del diagnóstico con `node herramientas/publicar-formulario.mjs`.
